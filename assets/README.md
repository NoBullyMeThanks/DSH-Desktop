# 图标资源（assets）

- `deepseek-official-fish-black.svg`：官方黑色鱼形矢量源文件。
- `icon.png`：1024×1024 应用图标母版，采用白色圆角底板、浅灰描边和黑色鱼形标志。
- `icon.ico`：包含 16、20、24、32、40、48、64、128 和 256px 的 Windows 图标，用于任务栏、可执行文件、桌面快捷方式及安装/卸载程序。
- `tray.png`：32×32 托盘图标，与应用图标使用相同的圆角底板设计。

修改图标后需要重新执行 `npm run build`。Windows 可能缓存已安装程序或固定任务栏快捷方式的旧图标，此时需重新安装，并取消固定后再次固定。
